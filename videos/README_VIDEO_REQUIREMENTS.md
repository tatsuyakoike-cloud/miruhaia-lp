# 動画3本の配置

このフォルダには実動画が入っていません。掲載許諾を確認した上で、次の3種類を置いてください。

1. `video-01.mp4`：社員インタビュー
2. `video-02.mp4`：仕事・現場紹介
3. `video-03.mp4`：会社・チーム紹介

ポスター画像は`posters/video-01.webp`〜`video-03.webp`を推奨します。

## 選定条件

- 砂建を除外
- 広告露出が大きく既視感の強い事例を除外
- Web掲載許諾が確認済み
- 人物・企業名・機密情報の公開範囲が確認済み
- 同業種・同画角に偏らない
- 標準的な制作品質を誤解なく示せる

## 技術条件

- 縦9:16、720×1280以上を目安
- MP4 H.264、Web向け圧縮、faststart
- 音声付き自動再生はしない
- 1本ごとにposterを作る
- `config/video-manifest.example.json`を複製し、許諾根拠を記録する
