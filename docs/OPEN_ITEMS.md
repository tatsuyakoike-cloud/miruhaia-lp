# 公開前の確認事項

以下はAgentが推測してはいけません。未確定でも実装は進められますが、公開完了にはできません。

- 問い合わせフォームURLまたは送信先
- プライバシーポリシーURL
- 運営会社の正式な会社情報
- 料金の税込／税別
- 15万円プランの契約期間・動画本数
- 20万円プランの契約期間・動画本数
- 30万円プランの「計8本」が月間・年間・契約期間合計のどれか
- 初期費用0円キャンペーンを掲載するか、正式な理由・期限・条件
- 動画3本の正式ファイル、企業名の表示範囲、掲載許諾
- 問い合わせ完了後の動作
- Google Analytics等の計測ID
- canonical URL・OGP URL・公開ドメイン
- 市場データの最終採用と原典確認

値は`config/site-config.example.json`と`config/video-manifest.example.json`を複製して管理してください。架空の値で穴埋めしないでください。
