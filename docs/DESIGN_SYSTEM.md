# デザインシステム

## 印象

信頼感、親近感、導入しやすさを優先します。SNSサービスらしさは動画の見せ方で表現し、黒背景・ネオン・過剰なモーションには頼りません。

## 色の面積比

- 70% ベース：`#FFFFFF`、`#FAF8F3`
- 20% メイン：`#6051C8`、`#493AAE`、`#EEEAFE`
- 8% アクセント：`#FFD84D`
- 2% ブランド補助：`#D64B4B`
- 本文：`#12152F`、補足：`#62677E`

## 余白とサイズ

- 最大幅：1200px
- PC左右余白：40〜64px
- SP左右余白：20〜24px
- セクション間：PC 112〜144px、SP 72〜96px
- カード角丸：24px
- 写真・動画角丸：32〜40px
- 影：濃紺12%以下の柔らかい影
- 本文：PC 17〜18px、SP 16px、行間1.7〜1.9

## 禁止

- 画面の大半を黒・紫で埋める
- ネオン調、TikTok風のシアン・ピンク
- 文字を焼き込んだ一枚絵
- 小さい文字の密集、長い比較表
- 不自然なAI人物、過剰な笑顔、偽のSNS画面
- 意味のない自動アニメーション
