# LP構成・文章仕様

対象はSNS・Webに詳しくない中小企業の経営者・採用担当者です。資料28ページをそのまま並べず、次の15セクションへ再編集します。

## 1. ヘッダー

ロゴ、`サービスの特徴`、`動画事例`、`料金`、`よくある質問`、CTA `まずは相談する`。

## 2. ファーストビュー

- 見出し：`見える会社は、選ばれる。`
- 補足：`ショート動画で、会社のリアルを採用力に変える。`
- 説明：`企画・撮影・編集・投稿・分析まで。採用のためのショート動画運用を、専任チームがまるごと支援します。`
- CTA：`無料で相談する`／`動画の品質を見る`

右側は実在感のある写真2〜3枚を縦動画カード風に配置します。文字と再生UIはHTML/CSSで重ねます。

## 3. 共感

見出し：`採用・求人で、こんなお悩みはありませんか？`

`応募が集まらない`、`若手に届かない`、`条件だけで比較される`、`社風が伝わらない`、`採用しても続かない`、`発信する時間がない`。

## 4. 市場と構造的な課題

見出し：`求人を出すだけでは、埋もれやすい時代です。`

- 正社員不足を感じる企業：50.6%（帝国データバンク、2026年4月）
- マイナビ転職では、2026年1月の求人件数が2023年平均比188.7%に対し応募数は127.7%
- 結論：`採用費が積み上がる一方で、会社の情報は残りにくい。`

数値は出典名・年月・リンクを付けます。

## 5. 原因

見出し：`採用が難しい本当の理由は、会社が見えていないこと。`

`条件だけで比較される`、`職場が見えない`、`入社後を想像できない`。

## 6. 求職者の変化

見出し：`求職者の約7割が、転職活動でSNS・動画を使う。`

大きな数値`69.8%`と、`求人を見る → SNS・動画で情報収集 → 人・仕事・社風を確認 → 応募を判断`を表示します。出典はマイナビの2026年1月度定点調査として、公開前に原典PDFも再確認します。

## 7. 役割の違い

見出し：`求人媒体とSNSは、役割が違います。`

- 求人媒体：今すぐ探す人へ募集条件を届ける
- SNS・動画：まだ知らない人へ会社のリアルを届ける
- 結論：組み合わせて応募前の不安を減らす

## 8. 解決策

見出し：`ミルハイアは、会社のリアルをショート動画で可視化します。`

`知ってもらう`、`理解してもらう`、`応募につなげる`。

## 9. 動画事例3本

見出し：`どんな動画をつくるのか、実際にご覧ください。`

- 社員インタビュー
- 仕事・現場紹介
- 会社・チーム紹介

PCは3列、SPは1本ずつ横スワイプ。砂建・広告露出の大きい事例は除外し、掲載許諾が確認できる動画だけを使います。

## 10. 支援範囲

見出し：`企画から分析まで、まるごと支援。`

`戦略 → 企画 → 撮影 → 編集 → 投稿 → 分析`。

## 11. 内容と応募導線

見出し：`発信するのは、会社のリアル。`

`仕事`、`文化`、`成長`、`採用`。導線は`視聴 → 興味 → 理解 → プロフィール・採用ページ → 応募`。

## 12. 運用体制

見出し：`専任チームが、迷わない運用を支えます。`

お客様側は`情報提供`、`撮影協力`、`内容確認`。メリットは`続けやすい`、`蓄積する`、`再利用できる`。

## 13. 違い

見出し：`初めてSNS採用に挑戦する中小企業に、ちょうどいい。`

`月15万円から`、`応募導線まで支援`、`専門担当がいなくても進められる`。

## 14. 料金

見出し：`会社の状況に合わせて、3つのプランから選べます。`

- 15万円：AI動画生成。サポート最小限、AIで量産。契約期間・本数は未確定
- 20万円：初回の素材撮影、素材展開、人物素材の組み合わせ、AIとのハイブリッド。契約期間・本数は未確定
- 30万円：12か月契約、2か月に1回撮影、計8本投稿。`計8本`の期間定義は未確定

税区分は確定まで表示しません。初期費用キャンペーンは、正式条件を確認できる場合のみ別パネルで掲載します。

## 15. 導入・FAQ・CTA

導入は`ご契約 → ヒアリング → 初回撮影・素材準備 → 投稿開始`。

FAQは、SNS未経験、撮影準備、顔出し、投稿確認、対応媒体、効果測定を扱います。

最終見出し：`まずは、御社の採用課題をお聞かせください。`
