# ミルハイア 制作担当向けアセット

最初に使うロゴは、`01_LOGO/01_PRIMARY_USE_THIS/`です。

このフォルダ内の`.ai`、`.svg`、`.pdf`、`.eps`はすべてベクターです。通常使用ロゴには白い背景オブジェクトを入れていません。PNGも背景透過を確認済みです。

## ディレクトリ

- `01_LOGO/01_PRIMARY_USE_THIS`：通常は必ずここを使用
- `01_LOGO/02_SYMBOL_ONLY`：ロゴマーク単体
- `01_LOGO/03_TAGLINE_LOCKUP`：タグライン・サービス説明付き
- `01_LOGO/04_MONO_NAVY`：単色印刷向け
- `01_LOGO/90_REVERSE_WHITE_FOR_DARK_BG`：濃色背景専用。白背景では使用しない
- `02_ICONS`：アイコン13種
- `03_ILLUSTRATIONS`：イラスト5種
- `04_PHOTOS`：JPEG写真、元PNG、4:5トリミング
- `05_DECORATIONS`：虹彩・フォーカス・縦型動画フレームなど
- `06_BRAND_GUIDE`：使い分けガイド、カラー、LPトーン＆マナー
- `07_SOURCE_EDITABLE_TEXT`：文字を編集したい場合の元SVGとフォント

## Illustratorでの使い方

- `.ai`：Illustratorで直接開けるレガシーAI互換ベクター。文字はアウトライン済み
- `_outlined.svg`：文字を含めてパス化済み。Illustrator・Figma・Webで使用可能
- `.pdf`：透明背景を保持したベクターPDF
- `.eps`：印刷・旧環境向け
- `.png`：背景透過の確認用・Web用

ロゴの文字自体を修正する場合のみ、`07_SOURCE_EDITABLE_TEXT`のSVGを使用し、同梱フォントをインストールしてください。

## 注意

白文字版は濃色背景専用です。通常ロゴと混同しないよう、`90_REVERSE_WHITE_FOR_DARK_BG`に分離しています。
